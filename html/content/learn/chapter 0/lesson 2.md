# What is C++?

C++ is a **general-purpose programming language** created by Danish computer scientist **Bjarne Stroustrup**. It was first released in **1985** as an extension of the C programming language.

C++ has evolved significantly since its creation. It supports several programming styles, including **procedural programming**, **object-oriented programming (OOP)**, and **generic programming**.

## What is C++ used for?

C++ is especially well known for its **performance**, **efficiency**, and **flexibility**. It gives programmers a high degree of control over how their programs use memory and other system resources.

C++ is commonly used to create:

- Desktop applications
- Video games and game engines
- Operating systems and system software
- Servers and backend software
- Databases
- Embedded systems
- Scientific and engineering software
- High-performance applications
- Aerospace and space-related software

## Why learn C++?

One of C++'s biggest strengths is its **flexibility**. You can use C++ to write programs that interact closely with computer hardware, while also using higher-level features such as **classes**, **templates**, and the **C++ Standard Library**.

C++ is also widely used in performance-critical software, making it a useful language to learn if you are interested in game development, systems programming, embedded programming, or high-performance computing.

C++ continues to evolve, with new versions of the language introducing features that make programs more maintainable, and easier to write.
